# Reasonix Homebrew Tap

Homebrew tap for [Reasonix](https://github.com/esengine/DeepSeek-Reasonix) — the
cache-first DeepSeek coding agent for the terminal.

## Install

```sh
brew install esengine/reasonix/reasonix
```

Casks in this tap are generated and pushed automatically by GoReleaser on each
`v*` release of the main repository. Don't edit them by hand.
